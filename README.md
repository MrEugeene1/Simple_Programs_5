# Python Works

Small Python practice project focused on list comparison and counting matches.

## Overview

The program compares two integer lists:

- drawn: the numbers that were drawn
- bets: the numbers selected by a player

It counts how many bet numbers appear in the drawn list and prints the total hits.

## File

- simplePrograms5.py

## How To Run

```bash
python simplePrograms5.py
```

## Example Output

```text
4
```

## Learning Focus

- list iteration with for loops
- membership checks using in
- counter updates with integer variables
